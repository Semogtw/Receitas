# Decisão: planejador de refeições sem notificações

Data: 2026-08-07

## Decisão aprovada

O planejador de refeições será **somente visual**.

- Não haverá lembretes ou notificações para refeições planejadas.
- Horário e período de refeição servem para organização e exibição no planejador.
- O planejador continua podendo alimentar a lista de compras.
- Notificações do sistema ficam restritas a funcionalidades em que são realmente úteis, como timers do modo cozinha quando a plataforma suportar.
- A UX não deve sugerir que uma entrada do planejador agendará alertas em segundo plano.
